About

Most of my work today is in TypeScript: full-stack platforms on Next.js, Prisma and PostgreSQL, built for real organisations, from pharmacies and multi-vendor marketplaces to creative agencies. I handle the whole path: data modelling, auth and role-based access, APIs, dashboards and analytics, then deployment on Vercel.

I started out with Flutter and Python, picked up React Native and Expo for mobile, and more recently went lower-level with C++ and Qt 6 to ship Omnipane, a native Windows launcher with its own installer and test suite.

I care about software that's fast, accessible and easy to operate once it's in people's hands.

  • Based in Lilongwe, Malawi
  • Focus Full-stack web · Mobile · Desktop
  • Now building PharmaStore & Omnipane

    Selected work

    Production systems and tools I designed and built end to end.

    Senior project Web platform Live

    PharmaStore

    A pharmacy management system and public medicine-availability search for Malawi. Two audiences share one database:

    • Customers search by brand, generic or local name, see which nearby pharmacies have it in stock with prices and opening hours, and reserve it for pickup.
    • Pharmacies run their dispensary on it: batch-level stock, point of sale, prescriptions, demand forecasting, expiry control, reordering and procurement.
    • Next.js
    • TypeScript
    • PostgreSQL
    • Prisma
    • NextAuth
    • Google Maps
    • Recharts
    Live site Source
    Native desktop Windows

    Omnipane

    A floating application launcher for Windows. Press Ctrl+Space, type a few letters, press Enter, and you're back to work.

    • Native Windows 11 acrylic window with DWM shadow and a spring-in animation that respects system motion settings.
    • Instant ranked search across prefix, word-start and initials (vsc → Visual Studio Code), including Store app icons.
    • Per-user MSI and portable builds, no admin rights needed, plus headless Qt Test suites run through CTest.
    • C++
    • Qt 6
    • CMake
    • Win32 / DWM
    • WiX
